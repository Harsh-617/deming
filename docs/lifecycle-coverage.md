# Lifecycle retrieval coverage: 30 rows vs 30 + extended

Generated by `python eval/lifecycle_coverage.py` (offline: no network, no LLM or Gemini call). Synthetic inventory.

**The published Deming results used only the original 30 rows of `data/lifecycle.csv`.** `data/lifecycle_extended.csv` is off by default. This page measures **retrieval coverage only**. The effect of the extended rows on lane accuracy has **NOT been measured**; that needs a new Gemini run.

- Before: `data/lifecycle.csv`, 30 rows.
- After: `data/lifecycle.csv` + `data/lifecycle_extended.csv`, 42 rows (`retrieval.load_lifecycle(..., include_extended=True)`, or `DEMING_LIFECYCLE_EXTENDED=1`).
- Device identity given to retrieval: the human-drafted `vendor`, `product`, `version` from `data/ground_truth.csv`, plus the inventory `firmware_version_raw`. Ground truth has no model column, so no model is given.
- Retrieval: `sim/retrieval.lifecycle_candidates`, top 5, unchanged.

## Measures

A returned row **matches** when its vendor equals the truth vendor and either its product equals the truth product or its `model_pattern` was tested against the device and fits.

| Measure | Meaning |
|---|---|
| any | a matching row is returned (with or without dates) |
| dated | a matching row with a support-end date (`eol_date` or `last_security_support_date`) whose pattern fits the device or is blank |
| name-only | a matching dated row whose pattern could not be tested (no model, or no version, in the truth identity). It may not apply to this device, so it is NOT counted as dated |

## Limits

- Retrieval coverage is not lane accuracy. No Gemini run used the extended rows.
- No model is in the truth identity, so model-specific hardware rows (Cisco RV, D-Link NAS, WatchGuard T35) can only be name-only here. In a real run the Normalizer's `model` field decides whether they fit.
- Rows are added only where a source states the date explicitly; the skipped products and why are printed by `python scripts/build_lifecycle_extended.py` and listed in `docs/decisions.md`.
