Deming: demo replay

Deming reads a synthetic device inventory, normalizes device names, checks them against CISA KEV and end-of-life data, assigns a lane (patch / retire / fine / unknown), drafts owner messages, waits for a human to approve, and on the next run checks whether the inventory record changed. This page replays one recorded run of the demo scenario (sim/demo_scenario.py, mock model, no API calls). The Verifier confirms the inventory record changed, not that a device is secure.
